# Install OpenSCAD

Use a current snapshot build: https://files.openscad.org/snapshots/

- Windows: `OpenSCAD-<date>-x86-64-Installer.exe /S`, then add the install directory (e.g. `C:\Program Files\OpenSCAD (Nightly)`) to PATH.
- macOS: snapshot `.dmg` or `brew install --cask openscad`.
- Linux: snapshot `.AppImage` or distribution package.

Check: `openscad --version`
