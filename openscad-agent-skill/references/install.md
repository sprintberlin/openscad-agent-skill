# Install OpenSCAD

- Windows: `winget install --id OpenSCAD.OpenSCAD --silent --accept-source-agreements --accept-package-agreements`, then add `C:\Program Files\OpenSCAD` to PATH.
- macOS: `brew install openscad`
- Debian/Ubuntu: `sudo apt install openscad`

Check: `openscad --version`. Release 2021.01 is sufficient.
